# W4 dataset record: WAW-TACE (made 2026-10-29, scouting only; no PREREG yet)

Data live OUTSIDE the repository (`waw_tace/` next to it on the local disk; never committed). Downloaded files are untrusted: each archive is extracted into its own empty directory and read with `python -I`.

| Item | Record |
|---|---|
| Dataset | **WAW-TACE: A Hepatocellular Carcinoma Multiphase CT Dataset with Segmentations, Radiomics Features, and Clinical Data**, Zenodo record 12741586 (version v2, published 2024-07-15; version v1 = record 11063785, published 2024-04-25; concept DOI 10.5281/zenodo.11063784) |
| Licence | **CC BY 4.0** (Zenodo `license.id` = `cc-by-4.0`). The record states access for scientific research use, with no co-authorship or collaboration requirement. |
| Dataset citation | Bartnik K, Bartczak T, Krzyziński M, Korzeniowski K, Lamparski K, Węgrzyn P, Lam E, Bartkowiak M, Wróblewski T, Mech K, Januszewicz M, Biecek P. *WAW-TACE: A Hepatocellular Carcinoma Multiphase CT Dataset with Segmentations, Radiomics Features, and Clinical Data* (v2). Zenodo, 2024. doi:10.5281/zenodo.12741586 |
| Paper | Bartnik K, et al. WAW-TACE: A Hepatocellular Carcinoma Multiphase CT Dataset with Segmentations, Radiomics Features, and Clinical Data. *Radiology: Artificial Intelligence* 2024;6(6):e240296. doi:10.1148/ryai.240296 (published 2024-10-23; PMC11605144). Ethics: approved by the Bioethics Committee of the Medical University of Warsaw (AKBE/41/2024); the article has no consent statement. |
| Source | One centre: Central Clinical Hospital of the Medical University of Warsaw, 233 treatment-naive patients with unresectable HCC treated with TACE monotherapy, May 2016 to April 2021; multiphase CT within 90 days before the first TACE cycle. Images de-identified, converted to NIfTI, not resampled or filtered. |
| Content | 854 CT series (phase 0 native 200, 1 late arterial 230, 2 portal venous 231, 3 delayed 193), 377 hand-drawn tumour masks (NRRD; 3D Slicer, TotalSegmentator extension as the starting point; one radiologist, reviewed by two; 3 mm Gaussian smoothing), TotalSegmentator organ masks per phase (104 VOIs), radiomics features, clinical data. No official train/validation/test split. |
| Files and checksums | The Zenodo record gives an MD5 per file; every downloaded file was compared with it (see `results/w4_waw/download_verification.txt`). Sizes: four CT archives 10.36, 10.50, 12.80 and 13.49 GB, organ masks 1.04 GB, tumour masks 2.3 MB, radiomics 22 MB, clinical data, metadata and definitions under 100 kB; 48.22 GB in total. |
| Where downloaded | The local disk, not the persistent filesystem: no GPU instance existed (the previous one was terminated) and every scouting step is CPU-only, so the data can be moved to the persistent filesystem when an instance is next launched (rsync of the `waw_tace/` directory). Download: `waw_tace/download_parallel.sh`, resumable (`curl -C -`), five parallel streams because Zenodo gives about 0.9 MB/s per connection. |
| Phase definitions | `ct_hcc_metadata_v2.csv`: `ct_phase` 0 native, 1 arterial, 2 portal venous, 3 delayed; `tumor_count` = number of tumour masks drawn on that series. The paper does not state which phase masks were drawn on; the metadata and the mask file names (`<patient>_<phase>_<index>_tumor_seg.nrrd`) show each patient's masks were drawn on ONE phase. |
