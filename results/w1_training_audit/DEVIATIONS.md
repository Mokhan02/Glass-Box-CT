# W1 deviations and post-data decisions

Format: number, date, what, why, and whether any contrast value had been computed when it was decided.

## 1. CRML-CT: which segmentation series and which segments (2026-10-12)
PREREG says "the DICOM-SEG liver segment minus all tumour segments (checked on the first cases)". The metadata survey (`scripts/w1_crml_survey.py`, `crml_series_survey.csv`, metadata only, no pixel data, no contrast) showed each patient has 2 or 3 SEG series:
- `Segmentation`, SegmentAlgorithmType MANUAL, 197 patients: segments Liver, Liver Remnant, Hepatic (vein), Portal (vein), Tumor_1..Tumor_N.
- `AIMI liver-tumor AI segmentation`, AUTOMATIC, 197 patients: Liver, Mass. An algorithm output, not a label.
- `AIMI liver-tumor radiologist 7 corrected segmentation`, SEMIAUTOMATIC, 27 patients: an AI segmentation corrected by one reader.
Decision: the expert label is the series whose segments are all MANUAL; AUTOMATIC and SEMIAUTOMATIC series are never used (they are model output). Segment roles come from `SegmentLabel` (exact match: `Liver`, `Liver Remnant`, `Tumor_<n>`), not from segment order or from the type code meaning, because `Liver` and `Liver Remnant` both carry the code meaning "Liver" and would be conflated. Liver mask = segment `Liver` only (remnant, veins and other segments are not used); tumour = union of `Tumor_<n>`; tumour voxels are removed from the liver by the contrast function. One manual series per patient is required.
Contrast values computed when decided: none (one prototype patient was run to test the loader; its value is not used for any decision).

## 2. CRML-CT: patient exclusion criteria, fixed before any contrast is computed (2026-10-12)
Applied by `scripts/w1_crml_extract.py inventory`, which computes no contrast. A patient is excluded, with the reason logged, if: no single manual series; CT or SEG cannot be read; a SEG frame cannot be placed on a CT slice by its referenced SOP instance; no `Liver` or no `Tumor_<n>` segment, or either is empty; CT slice gaps deviate from the median by more than 1 mm; fewer than 50% of tumour voxels lie inside the `Liver` segment, or tumour volume exceeds liver volume (label inconsistency, the guard against a liver/tumour swap). Patients with no tumour of at least 10 mm are kept but contribute no lesions; they are listed separately.
Contrast values computed when decided: none.

## 3. Reference-parenchyma parity with exp8: tumours and vessels (2026-10-13)
Found by review before any bright share, comparison or verdict was computed (commit 6f4f0ce contains only per-lesion contrast values for CRML-CT, no share).
What exp8 did for HCC-TACE-Seg: its liver mask is `seg == 1` in a single-valued label map (`scripts/convert_heldout*.py` writes frames in segment order, later segments overwrite earlier ones). So the HCC reference excludes EVERY tumour component (label 2, any size, not only the target lesion) and the labelled portal vein (label 3, and the aorta, label 4). Hepatic veins and other intrahepatic vessels are not labelled in HCC-TACE-Seg and therefore remain in the reference.
What the first W1 code did for CRML-CT: `lesion_contrast` removed only the target lesion from the `Liver` segment. CRML-CT's `Liver` segment contains the tumours (median 0.999 of tumour voxels lie inside it), so other tumour components (including sub-10 mm ones) and the labelled portal and hepatic veins were inside the CRML-CT reference. That is a parity bug: it biases the CRML-CT reference towards darker (other tumours) and, near vessels, brighter values, unlike the HCC reference.
Fix (code and tests): `case_lesions(..., exclude=)` builds the reference as `liver & ~(all tumour voxels of the case) & ~exclude`. For CRML-CT the primary reference is the `Liver` segment minus all `Tumor_<n>` segments minus the `Portal` vein segment, which is exactly what exp8's label 1 excludes. Sensitivity column `contrast_hu_no_hepatic_vein` also removes the `Hepatic` vein segment (HCC had no hepatic-vein label, so this is an additional deviation from HCC treatment, reported, not primary). MSD Task03: reference = label 1 (liver, excludes label 2 tumour, no vessel label), the same single-valued construction as HCC.
The first per-lesion table is kept in git as `crml_lesions_SUPERSEDED_pre_DEV3.csv` and must not be used. A phantom test (liver mask containing the target lesion, a second lesion and a bright vessel) asserts the shell excludes all three.

### 3a. Decisions recorded (2026-10-16, before any bright share was computed)
- **Primary reference (decided):** Liver minus ALL tumour segments minus the Portal vein (exact parity with exp8's label 1). `contrast_hu_no_hepatic_vein` (also removes the Hepatic vein segment) is a secondary sensitivity column.
- **Lesion counts reconciled.** 408 = ALL lesions of at least 10 mm in the 194 patients with one (the secondary "all lesions" set). The primary set is unchanged: the 2 largest per case, 301 lesions from 194 patients (87 patients with 1, 107 with 2; 107 = 408 - 301 lesions are rank 3 or later). Per-patient primary counts before and after DEV3 are identical for every patient; (patient, rank, diameter, volume, tumour HU) are identical row by row (`crml_primary_counts_before_after_dev3.csv`). The DEV3 fix changes only the reference, never lesion selection. "72 of 408" was the number of lesions (all, not primary) whose contrast moved by more than 1 HU between the superseded and corrected reference (52 of the 301 primary lesions). Three patients have no lesion of at least 10 mm: CRLM-CT-1007, -1008, -1139.
- **Pre-specified sensitivity variant `no_vessel_removal`** (Liver minus all tumour only; the only treatment MSD Task03 allows, since it has no vessel labels): computed for CRML-CT (column `contrast_hu_no_vessel_removal`) and, for HCC, by `scripts/w1_repro_hcc.py` on the Lambda instance (HCC label 3, the portal vein, is put back into the reference; the HCC volumes are not on this machine). Bright/dark class changes between variants are counted and reported; they never change the verdict.
- **CRML-CT class changes, counted before any share:** primary vs `no_hepatic_vein`: 2 of 301 primary lesions (2 of 408 all); primary vs `no_vessel_removal`: 0 of 301 (0 of 408); `no_hepatic_vein` vs `no_vessel_removal`: 2 of 301 (2 of 408). Largest contrast change: 15.6 HU (no hepatic vein), 5.3 HU (no vessel removal). HCC variant: pending the Lambda run.
