## 4. Per-arm bootstrap seed in `scripts/w3_analyze.py` (2026-10-20; researcher's instruction; before model D's analysis)
- **Why:** the analysis used one random sequence across all arms in alphabetical order, so an arm's bootstrap CI depended on which other arms were loaded (the VISTA reference row read [+24.0, +65.2] alone and [+24.3, +64.7] beside model A). Point estimates and verdicts were never affected.
- **Change:** each arm's bootstrap uses `np.random.default_rng(arm_seed(arm))`, with `arm_seed` = first 8 hex digits of SHA-256 of the arm name (stable across runs, machines and Python versions); an arm's results no longer depend on the other arms (unit test). 1000 resamples, percentile CIs, case-level resampling unchanged. `scripts/w2v3_analyze.py` (shared statistic helpers) is unchanged.
- **Re-run:** the model A (swin, shipped and raw) and VISTA reference-row analyses (primary, as-converted and excluded-case sensitivities) were re-run with the pinned seeds on CPU: **no verdict or model-level label changes**; CIs move by at most about 2 points at an end. The earlier shared-seed outputs are kept in `analysis_shared_seed_superseded/` and `reference_row/shared_seed_superseded/`; the pinned-seed outputs are the reported ones.
- Re-hashed in `code_hashes.txt` ("Deviation 4").
- **Decision logged:** the model A kidney arm (secondary, "possibly seen in training") is **skipped** by the researcher: in-distribution for model A and kidney was covered by W2. Not run.

- **What was committed (261b993):** shape equals input, no axis flip raises organ Dice, predicted-vs-GT organ centroid offset <= 15 mm. I built the centroid version from the researcher's earlier wording ("alignment check (centroid offset + shape/orientation)") and the diagnostic rule, not from a Dice-maximising translation test with a 5 mm per-axis limit. MODEL-SIDE cases are quality-flagged (primary keeps them, sensitivity excludes them); no largest-component filtering.

Model A's tumour verdict (GAP, detection and Dice) had already been seen when this gate was re-run, so for A the re-run is a report, not a pre-analysis decision; for D the decision precedes any D tumour metric.
